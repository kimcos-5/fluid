# 화공유체역학 설계과제

## 1. 문제 상황

- 목표 : Air supply system의 degisn.
- 구성 : pipe(내경 20mm), 90도 elbows x20, completely-opened gate valve x 6, wide open angle valve x 2
- 온도 : 섭씨 25도
- 목표 유량 : 0.0546m^3/s

## 2. 기타 물성치

- 섭씨 25도에서, 밀도 = 1.225kg/m^3, 점성계수 = 1.81 * 10^-5pa.s

## 3. 문제의 해결 방안

1. 마찰계수의 산출 : 입실론의 결정, Re의 계산으로 f의 결정
2. 압력 강하량의 계산
3. 최초의 P 계산.

## 4. 압력 강하

배관에 의한 압력 손실

delta P = (8 * rho 8 Q^2 / pi^2) * ( L / (D^5 * -1.8log[((입실론/D)/3.7)^1.1 + 6.9 * 점성계수 * pi D/ 4Q]^2))


장치에 의한 압력 손실

delta P = (8 * rho 8 Q^2 / pi^2) * sigma(L_k) / D^4

## 5. 정보

pipe : 내경(d), 길이/가격(price), 재질 정보(ecp), 최대 강도(stress), 제품명(symbol)

joint : 내경(d), 가격(price), 강도(stress), 제품명(symbol)

compressor : 가격(price), 소비전력(W), 유량(Q), 압력(P), 제품명(symbol)


## 6. 알고리즘

1. 상수 선언 : 길이, 유량, 장비 요구 압력
2. 직경 설정(d)
3. 각 직경에 대한 요구 스펙 계산 (마찰 손실, 압축기 방출 압력, 압축 동력)
4. 스펙과 카탈로그의 매칭
5. 총 비용 산출
